01 · WORKFLOWS

Multi-endpoint operations

A

Promote employee

  1. POST /staff/employeesCopy completed record
  2. DELETE /onboarding/{id}Remove old copy, only after step 1
B

Promote intern

  1. POST /staff/internsCopy + set manager
  2. POST /staff/employees/{id}/internsAdd manager link
  3. DELETE /onboarding/{id}Remove old copy last
C

Reassign intern

  1. PUT /staff/interns/{id}/managerSet new manager
  2. POST /staff/employees/{id}/internsAdd new link
  3. DELETE /staff/employees/{id}/interns/{internId}Remove old link last
D

Undo promotion

  1. POST /onboarding/restoreRestore durable copy first
  2. DELETE /staff/.../{id}Remove staff copy within 7 days
